# Model-aware subscription rotation

Selection uses the requested canonical model, not the provider catalog alone. Fresh account-authenticated Codex model catalogs establish dated access evidence. Operator model switches remain independent. Missing/failed/old catalogs are unknown, not proof of support or a permanent rejection. Image support is not inferred from the text catalog. Quota reads reuse the existing model discovery endpoint at most once per ten minutes per saved account snapshot, including failed-read backoff. Token/account identity changes and observed plan changes invalidate evidence. Discovery and previews never generate output or redeem credits.

Quota snapshots retain the reported plan, actual duration and model scope. Codex windows longer than one day except exactly seven days are retained as plan-period windows; the preview shows the actual number of days. They participate in admission without being relabelled 5h or weekly. Existing 5h/7d sort criteria leave other durations unreported. Percentages express relative headroom, never absolute comparable capacity. Known exhausted applicable constraints block routing even when sorting is disabled. Unknown or expired observations retain existing fallback behavior.

Reset-credit priority orders matches, other usable credits and no usable credits by expiry. It creates no segments. Explicit ordinary quota divisions own group membership/order; credit priority orders inside each resulting group. With zero or one ordinary sort it orders the full list. This avoids implicit reset pools and keeps existing half/P50/gap controls meaningful. Availability display grouping is independent. Automatic redemption remains separately consented, model-gated, last-resort and verified after recovery.

Each safe retry excludes attempted accounts and reevaluates current account permissions, holds and quota observations. The starting sequence policy revision is retained for a text request; later requests see newer policies. Round robin/sticky or fill-first selects within the current eligible preferred group; no stale sticky candidate can bypass admission. Existing error classification, output and unknown-work fences remain. Text retries have a five-minute admission deadline and a maximum of 100 attempted accounts; an already running upstream call retains its existing transport timeout.

Additive snapshot fields require no migration. Keep the observation reader/writer, model access resolver, preview/card consumers, dispatch gates and regression tests together when extracting upstream patches. Fork deployment machinery is independent.
